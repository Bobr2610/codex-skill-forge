# MVP Release Checklist

- [ ] Approved scope and phase gate; linked Jira issues are accepted or explicitly deferred.
- [ ] Build, formatter, linter, type checks, tests, and security checks recorded with evidence.
- [ ] Architecture/naming contract and known exceptions current.
- [ ] Migrations and compatibility risks reviewed; rollback path documented.
- [ ] UI/accessibility verification recorded where applicable.
- [ ] Changelog and SemVer/version scheme updated; release notes reference Jira.
- [ ] Monitoring, support owner, known limitations, and handoff recorded.
- [ ] Release owner approved; artifact/tag and evidence links recorded.
